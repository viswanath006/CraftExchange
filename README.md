# CraftExchange 🌿
> **Discover the Beauty of Handmade** — Direct from Machilipatnam to Conscious Homes.

CraftExchange is an upcoming online marketplace initiative connecting traditional Indian artisans directly with customers. By eliminating exploitative middlemen networks, CraftExchange ensures fair compensation, cultural preservation, and digital access for generational master crafters starting in **Machilipatnam and Coastal Andhra Pradesh**.

---

---

## 🏛️ The Machilipatnam Pilot Cluster
CraftExchange starts its grassroots movement in the historic Krishna District:
- **Pedana & Machilipatnam Kalamkari:** Centuries-old natural vegetable block printing using carved teakwood blocks.
- **Terracotta Pottery & Cookware:** Hand-thrown alluvial clay vessels from Kummaripalem and river delta clusters.
- **Traditional Temple & Filigree Jewellery:** Classical South Indian motifs crafted by local metalsmith guilds.
- **Natural Fibre Weaving:** Hand-braided Korai river grass mats and golden jute baskets.
- **Teakwood Home Décor:** Repurposed vintage printing block art and bell metal oil lamps.

## 🚀 Key Features

1. **Artisan & Patron Registration:**
   - Interactive role selector: *"I am an Artisan"* vs *"I am a Craft Patron"*.
   - Stores submissions locally and provides instant confirmation.
2. **Concept Preview Modals:**
   - Deep-dive into each craft's origin, sustainable materials, and artisan community story.
3. **Responsive Mobile-First Design:**
   - Touch-friendly hamburger drawer, sticky blurred header, and adaptive grid layouts.
4. **Vercel-Ready:**
   - Pre-configured `vercel.json` for zero-configuration instant edge deployments.

## 💻 Local Development

Run the lightweight local server without external dependencies:

```bash
# Clone the repository
git clone https://github.com/phanikaushik2630-ship-it/CraftExchange.git

# Navigate to project directory
cd CraftExchange

# Start the local server
npm start
# or: node server.js
```

Open your browser at `http://localhost:3000`.

---

## ☁️ Vercel Deployment

Deploy with one command using the Vercel CLI:

```bash
npx vercel
```

Or connect this repository directly in your [Vercel Dashboard](https://vercel.com/new).
